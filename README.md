## 修改内容

本包基于第三方修改版继续处理，通过修改 DEX 字节码和 AndroidManifest.xml 后重新打包、签名。

- 保留原修改版对列表、详情、覆盖层及插屏等广告的屏蔽处理。
- 禁用第三方修改者公告、更新检查模块的启动入口。
- 禁用已识别的广告 SDK 初始化及部分统计、性能和崩溃上报入口，调整相应组件、权限和采集配置。
- 清理相关广告初始化、轮换、失败回调日志，以及重新签名触发的认证器告警日志。
- 保留正常登录、内容浏览所需代码，以及相关状态判断和清理流程。

以上是已核对的静态修改范围，尚未通过实机抓包确认所有广告请求和统计流量都已停止。

## 关于会员功能

原修改版将部分客户端 Premium 状态判断设为已开通。这会影响客户端功能入口及广告判断，**不代表账号获得官方会员资格，也未确认能够访问全部服务端付费内容**。

静态分析发现原修改版还存在以下限制，本次未修复：

- 默认人气搜索使用预览／试用接口，缺少后续分页地址。
- 侧栏浏览历史入口被替换为 Pixivision 内容入口。

## 安装

1. 下载上面的 APK，在 Android 手机上允许对应文件管理器或浏览器安装未知来源应用。
2. 使用同一本地签名的上一版修改包可尝试直接覆盖安装。
3. 官方版或其他签名的修改版通常无法直接覆盖；如需卸载重装，请先确认账号凭据和本地数据，卸载会清除应用本地数据。

本包重新签名，签名私钥不上传仓库。

## 验证情况

- APK 打包、ZIP 完整性和文件对齐检查通过。
- DEX 校验值检查通过；最终日志清理版仅对声明位置进行字节码修改，之前的去广告和停上报处理保留。

- **未在 Android 设备上安装运行**，启动、登录、浏览、下载和实际网络行为仍需实机验证。

本包保留了第三方修改版的其他内容。现有静态检查不能证明整个安装包不存在恶意代码。
